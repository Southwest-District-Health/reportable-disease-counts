# reportable-disease-counts
Public chart of reportable disease case counts by county and condition, Southwest District Health, Health District 3. Counts below five are suppressed.

## Creator, Maintainer
Lekshmi Rita-Venugopal
Epidemiologist Program Manager 1, Southwest District Health

## About this chart

Case counts for reportable conditions in Health District 3
(Adams, Canyon, Gem, Owyhee, Payette, Washington counties).

Counts of fewer than five cases are suppressed and shown as a marker rather
than a bar. Conditions that have never reached five cases in any single
county-year are shown for the district as a whole, with no county breakdown.

Live page: https://southwest-district-health.github.io/reportable-disease-counts/

See REFRESH.md for the monthly update procedure.
